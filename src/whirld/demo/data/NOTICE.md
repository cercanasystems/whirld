# Bundled starter imagery

Contains modified Copernicus Sentinel data 2024, via Element 84 Earth Search.

Source: Sentinel-2 L2A item `S2A_10SFH_20240722_0_L2A`, acquired
2024-07-22T19:03:53.453Z. The exact source region, pixel crop, scale/offset
conversion, grid, byte size and SHA-256 are recorded in `sample.json`.

The distributed image is a cropped RGB derivative in canonical DN units. It is
provided under the [Copernicus Sentinel Data Legal Notice](https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice),
which permits lawful reproduction, distribution and adaptation with attribution.
The application's Apache-2.0 license does not replace these data terms.

The preview applies a display-only percentile stretch. Scores and labels are
model outputs and do not constitute ground-truth land-cover annotations.
